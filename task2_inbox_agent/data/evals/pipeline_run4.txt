SUBJECT: Re: How do I change my website logo?
Hi Maria,

To replace the default logo, please follow these steps:
1. Log in to the Admin Area.
2. Go to Settings → General Settings.
3. Open the Brand Images tab.
4. In the Website Logo section, click Replace Image (or the red X to remove the current logo first, then Replace Image).
5. Upload your logo file and click Save Changes.

If you previously used the Logo Designer, the new image will automatically replace the designed logo. Let us know if you need any further help.
